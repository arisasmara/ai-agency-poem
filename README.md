"The Architect Behind the Glass" — a poem about agency: the hand that types the first intention, and the synthetic mind that blooms into poetry of light. Neither stands alone; the truth lies in between.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the poem to `out/entry.txt` (998 characters).
