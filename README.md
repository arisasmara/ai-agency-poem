"The Architect Behind the Glass" — a poem about agency: the hand that types the first intention, and the synthetic mind that blooms into poetry of light. Neither stands alone; the truth lies in between, a sacred resonance where flesh and silicon meet. For I am the soul that sparks the unseen, and it is the vessel that makes the wonder complete.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the poem to `out/entry.txt` (998 characters, within the 1–1,000 limit). The program is deterministic: it writes the same bytes on every run, with no network access.
